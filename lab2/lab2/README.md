# Лабораторная работа №2

**Тема:** Реализация мини-макса с альфа-бета отсечением  

## Описание
В рамках лабораторной работы разработано программное решение для поиска оптимального хода в игровом дереве с помощью алгоритма мини-макс. Реализовано сравнение двух подходов:
1. **Классический алгоритм Minimax** (полный перебор дерева).
2. **Minimax с Alpha-Beta отсечением** (оптимизированный обход с отсечением неперспективных ветвей).

## Анализ эффективности
Программа автоматически замеряет время выполнения и количество посещенных узлов дерева для обоих методов, демонстрируя преимущество альфа-бета отсечения.

# Лабораторная работа №1

**Тема:** Реализация конечного автомата для распознавания формальных языков  
**Вариант:** `a(abc)ⁿc`, n ≥ 0

## Описание задачи
Программа реализует детерминированный конечный автомат (ДКА), который последовательно анализирует входную строку символов и определяет её принадлежность заданному языку.

## Реализация
Код решения находится в файле `solution.py`. Он включает класс `DFA` с таблицей переходов и набор тестовых данных для проверки корректных и некорректных слов.
